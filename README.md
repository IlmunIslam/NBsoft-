# NBsoft — Archived Asset Dump

> **⚠️ This repository is archived and read-only.**
> It was an early flat dump of Blender source files with no structure or
> documentation. Every asset in it now lives in a dedicated, documented
> repository — use those instead.

## Where these assets live now

| File here | Current home |
|---|---|
| `Mitochondria.blend` | **[mitochondria-3d](https://github.com/IlmunIslam/mitochondria-3d)** — with a newer revision of the model (2025-02) and full documentation |
| `Barrel (Game Asset).blend` | **[barrel-animation](https://github.com/IlmunIslam/barrel-animation)** — with a newer revision (2024-11-14) plus the Unity physics project built on it |
| `Colon.blend` | **[vr-colon](https://github.com/IlmunIslam/vr-colon)** — with the full Unity HDRP colon endoscopy project |
| `Stomach.blend` | **[stomach-endoscopy-simulation](https://github.com/IlmunIslam/stomach-endoscopy-simulation)** — the full Blender production folder and flythrough render |
| `Number Pad.Blend` | *Retained here only* — a standalone hard-surface modelling study with no dedicated project |

The copy of `Stomach.blend` in this repository (last updated 2025-10-14) is a
**delivered client build** and differs from the production base mesh published in
`stomach-endoscopy-simulation`. It is preserved here for reference.
